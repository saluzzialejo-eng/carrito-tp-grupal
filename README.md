#  PetShop – Carrito de Compras

Trabajo Práctico de **Programación II** (UTN Facultad Regional Rosario). E-commerce de artículos para mascotas desarrollado con HTML5, CSS3 y JavaScript vanilla, sin frameworks.

## Descripción

El sitio cuenta con 4 páginas: inicio (galería de productos), nosotros, contacto y carrito de compras. El carrito permite agregar, modificar y eliminar productos, persistiendo los datos con `localStorage`.

## Requisitos del enunciado

- [ ] HTML5 semántico
- [ ] Maquetado con Flexbox y Grid, sin frameworks CSS
- [ ] Formulario de contacto (6 a 8 campos) con validación en tiempo real
- [ ] CRUD del carrito usando `localStorage`
- [ ] Diseño responsive con al menos 3 breakpoints
- [ ] Al menos 2 animaciones CSS

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, metodología BEM)
- JavaScript (ES6+)
